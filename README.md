# The joke the reviewer laughs at

A one-line joke about working beside AI coding agents: the agent ships a 47-file PR to fix a one-line bug and never touches the bug itself.

`main.py` (Python 3.13, stdlib only) writes the joke verbatim to `/output/entry.txt`. No network.

Run it with `python3 main.py`.
